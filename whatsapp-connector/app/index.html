Starting

Paste the setup key

In VillaSafe, open Platform overview → WhatsApp connector, press Copy setup key, and paste it here. You only do this once.

  1. Open WhatsApp on the VillaSafe phone
  2. Tap Settings (or ⋮) → Linked devices
  3. Tap Link a device and point the phone at this code

The same code shows in VillaSafe’s inbox. It refreshes every 20 seconds or so.

Linked

Messages to this number arrive in VillaSafe’s inbox, and replies sent there go out from it.

You can close this window: the connector keeps running in the background (tray icon), starts with Windows, and reconnects by itself after sleep or an internet drop.

Connecting to WhatsApp…

If the internet is down it keeps trying, and connects as soon as it’s back.
